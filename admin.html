Publier en ligne

Envoie directement vos modifications sur le site — aucun fichier à télécharger ni à déposer. Le site public reflète le changement en ligne sous environ une minute.

Solution de secours hors ligne. Si la publication en ligne ci-dessus est indisponible, vous pouvez toujours télécharger les fichiers ci-dessous et les déposer manuellement chez votre hébergeur.

Télécharger les données

Contient les produits, la photothèque et les avis. À placer dans le dossier js/.

Télécharger les textes

Contient les coordonnées, les textes d'accueil et les réglages. À placer dans js/.

Télécharger les images modifiées

Archive contenant uniquement les photos que vous avez changées, déjà redimensionnées.

Régénérer les fiches produit

Décompressez l'archive à la racine du site en conservant les dossiers (images/photos/, images/gallery/, images/testimonials/), puis remplacez js/data.js et js/site-config.js. À la racine, exécutez ensuite npm run generate:products : cette étape met à jour les fiches indexables du dossier produits/ et le sitemap.xml.

Mettre en ligne manuellement

Envoyez les fichiers remplacés, le dossier produits/ régénéré et sitemap.xml chez votre hébergeur. Si vous ne pouvez pas exécuter Node.js, transmettez les exports au mainteneur du site. Rechargez le site avec Ctrl+F5 pour vider le cache.

Réinitialiser

Efface votre brouillon local et revient aux fichiers actuellement en ligne. Les fichiers déjà publiés ne sont pas touchés.
